> 2026-10-09 更新：真人相機使用長衣身＋獨立袖子、骨架驅動三角網格、worldLandmarks 側身估計與髮／臉／皮膚語義遮擋。請先讀 `assets/REALISTIC_ART.md`。目前貼合程式在 `garment-rig.js`、`ar.js`、`composite.js`；下列 3D 服裝與動畫風貼圖說明只適用結果人偶及舊 renderer，不代表真人 AR。舊文的「不用改追蹤／相機流程」不適用骨架貼合與遮擋修正。

每一項都可以單獨改，改壞了也只影響外觀。

## 1. 換布料貼圖（最簡單、效果最大）

在 `data.js` 的角色裡加上 `art`，指向你畫好的圖（png 或 jpg，放在 `assets/角色id/`）：

```js
devote: {
  ...
  art: {
    haori: 'assets/devote/haori.png',   // 羽織身體（整件攤開）
    sleeve: 'assets/devote/sleeve.png', // 袖子
    inner: 'assets/devote/inner.png',   // 內襯（「全套」才看得到）
    hakama: 'assets/devote/hakama.png', // 袴（「全套」才看得到）
    weapon: 'assets/weapons/akari.glb', // 角色自己的武器模型（可選）
  },
},
```

貼圖怎麼對應到身上，看 `assets/templates/`：

- `haori_uv.png`（2048×1024）：羽織像一件**從正面中線剪開、攤平**的布。
  左右 = 繞身體一圈（最左是左前襟 → 左側 → 背中央 → 右側 → 最右是右前襟）；
  上緣 = 衣領／肩膀，下緣 = 下擺（大腿中段）。背上的大圖案（家紋、大花）畫在正中間。
- `sleeve_uv.png`（1024×1024）：袖子是一個筒。左右 = 繞手臂一圈，上 = 肩膀，下 = 袖口；手肘大約在 40～50%。

建議：
- 動畫風的圖最好：**色塊平塗＋清楚的花紋**，陰影交給程式（會自動加三階明暗和黑色描邊）。
- 不要把陰影、皺褶畫死在貼圖裡，衣服會動，畫死的陰影會跟光線打架。
- 貼圖有填時，`haori`／`haori2`／`pattern` 這些顏色設定就不再用於羽織本身（滾邊、袖口仍用 `trim`）。

## 2. 換武器模型

- 格式：`.glb`（Blender 匯出 glTF Binary）。
- 擺法：**握柄中心在原點、刀尖朝 +Y**。長度單位 = 使用者的軀幹長（約 50 公分），
  所以一把打刀全長大約 2.2（刀身 1.75＋刀柄 0.38）、小太刀大約 1.3。
- 放在 `assets/weapons/`，然後：
  - 所有人共用的「武士刀」「小太刀」：填 `data.js` 最上面 `WEAPONS` 的 `model`。
  - 某個角色自己的武器：填那個角色的 `art.weapon`。
- 模型載入失敗會自動改回程式畫的刀，不會壞掉。

## 3. 調整衣服的形狀（需要改程式，交給 GPT 時把這段貼給它）

全部在 `render3d.js` 的 `Outfit` 類別：

| 想改的 | 位置 |
|---|---|
| 羽織的寬度、長度、下擺張開多少 | `TORSO` 陣列：每列是 [離肩線高度, 寬半徑, 厚半徑]，單位是軀幹長 |
| 正面敞開多大 | `gap(v)` |
| 下擺皺褶深淺、條數 | 羽織 `mod:` 裡的 `depth`、`crease(th * 5.5 …)` |
| 袖子多寬、多垂 | 袖子段落的 `r`、`sag` |
| 手肘皺褶 | `bunch` |
| 布料甩動的幅度與彈性 | `Spring(55, 7)` 等：第一個數字越大越硬、第二個越大越快停；`multiplyScalar(-.07)` 是甩動幅度 |
| 明暗階數、描邊粗細 | `toonRamp()`（三個亮度值）、`thick.value = T * .026` |
| 打光方向 | `Stage3D` 裡的 `key`／`fill`／`rim` |

**不要改**：`ar.js` 的 `fromLandmarks`、`matchPose`、`placePose`（追蹤與比對），`app.js` 的相機流程。

## 4. 招式姿勢

在 `data.js` 每個角色的 `move.pose`：13 個關節點的座標（兩髖中點為原點、軀幹長 = 1、y 往下、已鏡像）。
可以照參考圖（動畫截圖）量出每個關節的位置填進去；`blade` 是刀的方向、`hand` 是持刀的手。

## 5. 版權界線（改圖時一樣適用）

可以：傳統紋樣（市松、鱗、麻葉、青海波⋯）、羽織／武士刀／小太刀這類通用服飾與武器、原創角色。
不要：原作角色名、臉、招牌配件（花札耳飾等）、作品標誌與名稱、已註冊商標的羽織圖案（龜甲紋、蝶翼紋、火焰紋）。
