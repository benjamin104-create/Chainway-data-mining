# 自動美顏 v15（2026-10-10）

v16 已改用較大範圍積分影像美肌、提高補光、加入強度與實際啟用狀態；最新內容與限制見 [V16_NOTES.md](V16_NOTES.md)，以下保留 v15 設計紀錄。

預設「標準」，另有關閉／男神／女神；選擇記在本機，可用 `beauty=off|standard|hero|goddess` 預選。男神／女神是可自由選擇的風格名稱，不做性別推論。

沿用同 repo `stand-filter` 美肌、補光、氣色、眼下柔和的方向，但這裡只處理臉部；不是移植全人像柔焦，也不修改另一個網站。沒有瘦臉、大眼、換臉、美白目標膚色或新的雲端服務。

使用既有 Pose 的眼睛／耳朵／鼻子／嘴部點建立旋轉橢圓。只有可靠且較正面的臉才啟用；背景、頭髮、五官、衣服、武器不一起柔焦。眼睛／眉毛／嘴唇的柔邊區域保留；依本人鼻側／臉頰色差遮罩做邊緣保護美肌、陰影補光、淡暖氣色。暗鬍鬚及高反差邊緣保守處理。

不靠 Canvas filter，使用小範圍像素運算，避免 Safari 不支援 filter 的情況。即時 ROI 長邊最多 224 px、照片輸出 384 px；同一套預設與幾何、不同工作解析度，並非逐像素相同。模型仍看原始影格；美顏在真人背景後、服裝／道具合成前執行，預覽及匯出使用同一效果。ROI 平滑可能損失部分皮膚細節，強側臉／遮臉保留原圖；不是完整 3D 臉模型或商用美顏 SDK。

新增純函式測試：來源像素不改寫、臉外透明、眼嘴保留、關閉無效果、可靠性／側角門檻、自適應膚色、四種預設。手機實際效能與真人膚質仍需實測。

本機 Edge 390×844：四種選項、套用／關閉狀態、照片立即重繪、男神模式輸出 1086×1448，無控制台錯誤；九組 Node 測試與所有 JS 語法檢查通過。使用 AI 示範照片，未使用或發布私人參考照；沒有把桌面測試當作手機實測。
