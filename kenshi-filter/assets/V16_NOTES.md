# v16 — 肩部定位、美肌可見性、自拍奧義（2026-10-10）

## 原因及調整

背景只在下一次姿勢辨識到期時更新快照（33 ms 節奏），兩者讀同一影格；不再在中間幀前進背景、沿用舊骨架。啟動時模型尚未可用，仍可看相機；單次辨識耗時與姿勢平滑仍會增加實際延遲，並非保證 30 FPS 或零延遲。

1. v15 的相機以推估 3D 點做整體擬合，並非每一個肩點都與觀察到的 2D 位置重合。現在 `rayAlignedPoint` 保留推估深度，將各點放回其觀察射線；校正前誤差仍顯示，不把它報成新測得的深度或尺碼。加快可靠姿勢的 2D／深度跟隨，保留低信心關節限制。
2. 上肩裁片應覆在關節中心之上。新上緣以肩部、後頸、較低的前開襟分開建形；後頸抬高只作用在靠近頸部，避免兩側長出站立的布片。袖根抬高至關節上方。移除手臂信心門檻翻轉就重建全部布料的 signature；袖子的前側肘／袖口支點保持拓撲，不可見時由既有保守姿勢回退支撐。
3. v15 的四點局部平均與強度太保守。新積分影像美肌有較大的柔化半徑、五官／邊緣／相對膚色保護，增加陰影補光。標準／男神／女神仍是風格選項，新增 60–160% 強度，保留關閉原圖對照。眼點可靠性門檻由 .55 改為 .42，但仍檢查鼻子、雙眼、距離、側向偏移。狀態只有實際產生面部遮罩像素才顯示「已啟用」，不只看設定開關。
4. 原奧義只在挑戰模式吻合達標出現，而且尺寸跟軀幹 T 一起增大，上半身自拍時容易跑到畫面外。新增「奧義拍照」：真人骨架可用即可手動發動，挑戰仍可達標自動發動。2.8 秒屬性光帶、速度線、粒子＋橫排大字，以視窗決定範圍；發動時收起一般選項，保留拍照。支援減少動態設定、沒有畫面震動或閃爍白屏。
5. 約 850 ms 自動拍照，衣服必須通過既有 5% 拉伸門檻；未通過時重試至 2.6 秒，不放寬門檻、不匯出失效照片。奧義輸出固定使用 .72 秒的特效峰值，人物／衣服仍為已追蹤的當下影格，不改換使用者臉部或姿勢。
6. 搞笑武器有獨立大字名稱：拔鞘一閃、蚊蟲退散、塵世斷絕、喵之誘惑。雞毛撢子的柄與羽毛頭補上連續接管；自拍模式按可見空間縮小搞笑道具，避免上方被截斷。這是構圖輔助，不是實際武器尺寸驗證。

## 驗證與邊界

十組 Node 測試（新增 `ultimate.test.mjs`），涵蓋射線校正、肩部覆蓋／前領高度、原有物理、素材、武器、五官保護、強度、特效有限值／文字／屬性／到期與道具構圖。抬手測試暫態拉伸 6.18%，超過 5% 的幀仍禁止匯出；2 次姿勢重定位後收斂到 2.63%。沒有隱藏暫態失效或把近似布料稱作完美物理。

本機 Edge 手機尺寸：照片試穿能發動「撢之奧義・塵世斷絕」並自動產生照片，美肌強度可用、關閉可還原。提供的戴眼鏡截圖只在 localhost 的瀏覽器記憶體做辨識回歸：面部可用、布料 3.2% 拉伸、無控制台錯誤。它已含舊 AR／瀏覽器介面，不能當成原始真人照片或精準身形對照，也不是實際手機相機延遲測試。私人圖片不複製到 repo、不進部署；對外示範沿用既有 AI 模特圖。

依然是 RGB 姿勢／深度推估＋程序裁片＋局部物理，不是個人化人體掃描、精準服裝紙樣、完整自碰撞或真正材料試衣。任意角度完美合身、遮擋背後的身形、商用尺碼與固定手機 FPS 尚不能保證。
