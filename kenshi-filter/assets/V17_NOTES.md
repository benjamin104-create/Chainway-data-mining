# v17 — 連續肩面、後頸摺領與前襟扣飾（2026-10-11）

## 結構調整

v16 衣身有上方開口，只抬高上緣仍缺少頸口至外肩的表面。新增連續肩部裁片，內界繞後頸，外界逐點接到已求解衣身的上環，保留前開襟；不再靠高硬肩線擋住原衣。降低外肩與袖根的抬高量，形成由頸至外肩的坡度。

領口沿後頸延續至左右前襟，有真正網格寬度、向外摺起的厚度和陰影。預設深色織布，可在「造型 → 領口與前襟」選同布摺領，避免舊灰色內襯色條。

預設米白毛球；也可選金屬羽織扣或不加扣飾。繩索與扣飾跟著已求解的兩側前襟，位置在上胸；附扣時衣身兩側有距離約束，關閉則移除。毛球用球面及短纖維輪廓，繩索維持同一網格拓撲，不逐幀重建幾何。

## 驗證

十一組 Node 測試及所有頂層 JS 語法檢查通過。新增測試包含肩面外界零接縫差、頸口範圍、摺領前凸、前襟約束通過原有 5% 拉伸匯出門檻、扣飾切換／有限值／幾何重用／釋放。抬手序列暫態最大拉伸 5.60%，超過 5% 的幀仍禁止匯出，兩次重定位後收斂至 2.70%；不是隱藏暫態或提高門檻。

本機 Edge 390×844：AI 模特照片試穿實際顯示深色及同布領、毛球及扣飾；1323 個布料頂點、185 個肩面頂點，拉伸約 2.6%，產生 1086×1448 照片，無控制台錯誤。使用者的舊 AR 截圖與一張側傾真人羽織參考圖只在本機測試，因視角估計未通過而未匯出；不能把它們當成新模型合身驗證。私人附件不複製至 repo 或部署。

## 邊界

肩面、摺領與扣飾是骨架／衣身支撐面，不是有獨立質量與縫合碰撞的完整布料裁片；畫面物理報告明列，不將它們加入既有估計衣重。RGB 人體深度與頸口仍為推估，原衣非常寬大、嚴重側身或遮擋時仍可能穿幫。中央開襟保留原衣是預期，外肩露出原衣不是理想結果。此版不是個人掃描、商用尺碼驗證或任意角度完美合身。
