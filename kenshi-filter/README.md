# 心之型・劍士測驗（大正劍士篇）

「在人群裡，你是哪一型劍士？」手機網頁小遊戲：十個任務情境題 → 六種「社會姿態」之一 → 對應的原創劍士角色 →
打開 AR 相機，穿上他的羽織、拿起他的武器，照著招式框擺姿勢，到位就自動發動特效並拍照。

## 六種社會姿態（阿德勒：人怎麼面對人際關係）

| 姿態 | 角色 | 紋樣 | 武器 | 招式（AR 招式框） |
|---|---|---|---|---|
| 犧牲奉獻型 | 燈之劍士・灯里 | 七寶 | 打刀 | 燈之型・守火上段（雙手高舉） |
| 疏離獨行型 | 月之劍士・朔 | 立涌 | 細身長刀 | 月之型・側身居合（側身水平橫斬） |
| 渴求認同型 | 陽之劍士・晴 | 矢絣 | 打刀 | 陽之型・昇天一閃（斜上舉刀、另一手叉腰） |
| 好勝爭先型 | 雷之劍士・迅 | 稻妻 | 雙短刀 | 雷之型・疾走雙斬（側身弓步、刀拖身後） |
| 扛責守序型 | 岩之劍士・巌 | 龜甲 | 大太刀 | 岩之型・不動構（刀直立胸前） |
| 和合共感型 | 潮之劍士・汐 | 青海波 | 薙刀 | 潮之型・迴流（雙臂張開） |

每一型的結果頁：健康的樣子、用力過頭的樣子、阿德勒觀點、馬斯洛需求的下一步、這週的小練習、
「你和誰比較像」（和六位劍士的相似度）。題目、文字、配色、招式姿勢全部在 `data.js`。

## 朋友比一比

結果頁「分享比一比連結」會把你的分數壓成網址參數（`?vs=六個字&t=類型&n=暱稱`）。
朋友打開、做完測驗，結果頁會多一張卡：你們的相似度 % 和兩種姿態的相處提醒（`data.js` 的 `PAIRS`）。
不需要伺服器、不收集任何資料。

## AR 怎麼做的

- 姿勢辨識：Google MediaPipe Pose Landmarker（lite），**在手機上計算**，影像不上傳。程式庫與模型都在 `lib/`、`models/`。
- 服裝：依肩、肘、腕、髖、膝、踝的位置即時畫出羽織（含紋樣）、寬袖、袴；**頭和手露在外面**。側身時肩寬會變窄，羽織會自動保持最小寬度蓋住身體。
- 武器：握在手上、方向跟著前臂；雙手靠近時改成雙手持刀。揮得快會出現刀光。
- 招式框：把該招式「預先算好」的目標姿勢（連服裝角度、刀的方向）放到你身上，以你的髖部為錨點、依你的身高縮放，淡淡地疊在畫面上。
  每一段肢體到位就會亮起；吻合度超過 80% 並保持 0.65 秒 → 招式發動（屬性特效＋直排招式名）→ 自動拍照。
  左右相反也算；腿沒入鏡時只比上半身。招式姿勢座標在 `data.js` 每個角色的 `move.pose`。
- 沒有相機（或在網址加 `?demo=cam&c=detach`）時，會用示範人偶演示服裝與招式。

## 版權

角色、名字、服裝花色、招式名都是原創；只使用「大正浪漫劍士」這種共通題材和日本傳統紋樣（紋樣本身沒有版權）。
**不要**換成任何漫畫／動畫原作的角色、花色（例如特定作品的格紋羽織）、名字或招式名，也不要在宣傳標題用作品名稱——
要用原作角色必須先取得版權方授權。

## 本機測試、上線

    python3 -m http.server 8000      # 開 http://localhost:8000 ，示範模式：/?demo=cam

上線方式和 `stand-filter` 一樣（Netlify，Base directory / Publish directory 填 `kenshi-filter`）。
相機需要 https。LINE 內建瀏覽器會自動改用手機瀏覽器開啟。
