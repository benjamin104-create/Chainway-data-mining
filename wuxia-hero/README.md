# 江湖英雄榜・武俠篇

你是哪一位武學奇才？向金庸武俠小說致敬的性格小遊戲＋AR 招式相機。

網址：https://jaminepa-wuxia.netlify.app

## 流程

1. 十個江湖情境（客棧不平、奇遇、被誤會、敵人示好、紅粉知己遇險、閉關、武林大會、宿敵、月下、傳說）
2. 算出六種俠客性格（守護、豪情、深情、仁厚、率真、機變），最後一題選剛猛或靈動 → 十二位英雄之一
3. 抽英雄籤 → 結果頁（六角圖、江湖分析、本命招式）
4. AR 相機：英雄站在身邊，美顏與前三篇相同；下方「⚔️ 練一招」教你比本命招式的手勢，「🀄 換英雄」可請其他英雄出場（絕招只有本人能用，英雄與招式不混搭）

## 字型

毛筆字以青柳衡山的「衡山毛筆フォント」（fonts/kouzan-mouhitsu.woff，主要）與「衡山毛筆フォント行書」（公有領域，可自由使用、改作、再散布），
只保留會用到的字（fonts/kouzan-gyosho.woff，約 60 KB）。行書裡缺的「你俠哪挪橫繡」
用同作者的「衡山毛筆フォント」補（fonts/kouzan-mouhitsu.woff）；「黃」「虛」借用字形幾乎一樣的「黄」「虚」。
改了英雄名字或招式名稱，要重新產生這兩個字型檔，不然新字會退回一般字體。

## 挑戰模式（game.js，太鼓達人風）

相機下方「🥁 挑戰」，配樂是 sfx.js 當場合成的武俠決鬥曲（150 BPM：太鼓、古箏琶音、低音弦樂、笛子／胡琴主旋律、鑼鈸），音符都落在拍點上。
- 手勢音符（握拳、手刀、比讚＝紅；張手、劍指、插眼＝藍；大音符分數加倍）從右往左跑到判定鼓：良／可／不可
- 絕招串：每位英雄一串框起來的手勢（見 COMBOS），全中 → 格鬥遊戲式切入（英雄圖＋毛筆招式名）＋分數 ×2 直到失手
- 韋小寶是搞笑秘技：插眼（V 手勢）→ 手刀 → 再一刀 → 劈喉嚨，漫畫爆炸框；連打段是「連環手刀」
- 連打：手刀一開一合連續劈，劈越多下分越多
- 魂量表：結束時超過 80% 顯示 CLEAR!；最後壓軸如來神掌・萬佛朝宗
- 開始自動錄影（音樂音效一起錄），結束自動停止
挑戰與絕招用到的字也要放進毛筆字型檔（見上方「字型」）。
