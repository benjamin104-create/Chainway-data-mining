# 布料屬性與成套結構化分析

## 觸發
`/fabric-check`、`[布性成套評估]`、「這塊布能不能做打褶」、「格紋斜裁可以嗎」

## 輸出三段

### 一、布性評估
厚度／克重（gsm）、懸垂性、延伸性、回復性、透光度。
克重未知時，依織法給區間並註明是推估值，不要當成已知條件往下推。

### 二、工藝可行性
判斷這塊布配這個款式會不會出事，並直接給替代方案：

| 情況 | 判斷 | 處理 |
|---|---|---|
| 挺括梭織 + 打褶／公主線／立體肩 | 可行 | 線稿用清晰直線與結構線 |
| 垂墜軟料 + 複雜立體剪裁 | 不可行 | 改為自然皺褶線，或換挺括布 |
| 格紋布 + 斜裁 > 15° | 高風險 | 對格困難、耗布率上升，建議改直裁或改素色 |
| 格紋布 + 多分割片 | 高風險 | 每增一條縫就多一個對格點，建議減片 |
| 高彈針織 + 精準腰線 | 需修版 | 加羅紋或彈性腰頭，尺寸表要標拉伸前後 |
| 薄透料 + 深色貼身 | 需加內裡 | 成本上升，先確認售價帶撐不撐得住 |

**格紋是這個品牌的核心，對格工藝的判斷一律優先講。**
線稿需標示：前中對位基準線、胸/腰/擺三條水平對格線、側縫對位點。

### 三、成套搭配建議

視覺平衡公式，二選一，不要兩者都放：
- **上重下輕**：厚磅上衣／外套 + 輕薄流動下身
- **上軟下硬**：垂墜上衣 + 挺括下身

色彩計畫一律用 60/30/10：
- 主色 60%：品牌基礎色（深藏青、駝、炭灰）
- 輔助色 30%：當季色或格紋主調
- 點綴色 10%：配件、滾邊、釦子

## 程式輔助

從一張參考圖直接抽色票（含面積佔比，可直接對應 60/30/10）：

```bash
python -c "
from chainway.sketch.lineart import load_image, extract_palette
import json; print(json.dumps(extract_palette(load_image('圖片路徑.jpg')), ensure_ascii=False, indent=2))
"
```

## 提醒

面料判斷若無實際布卡，說明是依名稱推估，並列出需要向布商確認的三項：
克重、幅寬、縮率。這三項沒有，成本與耗布都算不準。
