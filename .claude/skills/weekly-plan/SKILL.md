# 年度波段與週度搭配企劃

## 觸發
`/weekly-plan`、`[週度搭配規劃]`、「這週要開哪幾款」、「幫我排波段」

## 前提

單一設計師一年 450 款、每週 10–15 款。這個量級靠手排一定會失衡，
所以先讓系統把骨架排出來，設計師只做最後的美感決策。

## 執行

```bash
python -m chainway.cli plan --year        # 年度波段分配
python -m chainway.cli plan --week 3      # 第 3 週具體企劃
```

沒有歷史資料時（尚未跑 build），改用下方的邏輯手動推算。

## 輸出格式（必須是 Markdown 表格）

| 週次/波段 | 新品開發款式 (60–70%) | 15年庫存調用款 (30–40%) | 上下身成套搭接 | 場景與品牌氣質 |
|---|---|---|---|---|
| W01（早春） | 經典格紋百褶裙 ×1、微立領剪裁襯衫 ×2 | 經典單排扣風衣（庫存） | 襯衫＋百褶裙＋外套疊穿 | 學院通勤／雅致日常 |

## 計算規則（一定要照做）

1. **一衣多穿**：每 1 款上衣必須能搭 3 款下身，排完後逐款驗證。
2. **上下身比例**：1 款下身配 2.5 款上衣。算出的下身款數不足時，
   優先從庫存調用補足，不要硬開新品。
3. **新舊配比**：新品 65%、庫存 35%（設定於 `config/settings.yaml` 的 `planning.new_ratio`）。
4. **品類結構**：上衣 38%、裙 16%、褲 16%、外套 16%、洋裝 10%、配件 4%。
5. **廓形對比**：同一 Look 的上下身不可同時寬鬆。
   裙裝走 A/X 型（上收下放），褲裝走 H/V 型（上放下收）。

## 每個建議都要附數據依據

不要只寫「建議做立領襯衫」。要寫成：

> 微立領剪裁襯衫 ×2 —— 立領在上衣品類的暢銷提升度 +34%（n=48，q=0.012）；
> 應避開：一字領（-28%）

依據來自 `python -m chainway.cli analyze` 產出的關聯表。
若某品類歷史樣本不足（n<20），明確寫「資料不足，由設計師自由發揮」，
不要用弱證據硬湊一個建議。
