# 全民律動王（舞蹈篇）

手機立起來、退後兩步，跟著動作卡跳舞；鏡頭即時判斷全身動作，跳完自動錄影、給分數，可以上傳排行榜。

網址：https://jaminepa-dance.netlify.app

## 玩法（參考 Just Dance、Dance Central）

* **跟著拍子跳**：開場數「5、6、7、8」，一個舞步＝每一拍一個姿勢的循環（例如 拍手→張開→拍手→張開），重複一到兩小節才換（簡單、普通兩小節，困難一小節）
* **大舞者示範**：右上的舞者每一拍準時到位、跟著節奏上下彈，下面 8 個點是「一個八拍」數到哪
* **固定編舞**：每首歌主歌一套、副歌一套，副歌會重複（跳第二遍就記得）；同一首歌、同一難度每次都一樣（排行榜公平）
* **判定**：每一拍前後一小段時間內取最像的一格；不能只停在舞步的另一個姿勢（站著不動不會得分）；在拍點上做錯的手會變紅
* **五級評價**：PERFECT／SUPER／GOOD／OK／X；金色動作（每段結尾的定格大招）只有 YEAH 或 X
* **滿分 13333**：五顆星 10000、SUPERSTAR 11000、MEGASTAR 12000（皇冠）
* **自由舞**：歌曲中段兩小節，動越大分越高，自動拍下精彩瞬間，放在結束分數卡上
* **練習模式**（像 Dance Central 的 Break It Down）：一個舞步一個舞步學，慢速＋節拍器，連續 4 拍做對才換下一個
* **雙人對戰**：兩個人並排站，左 1P 右 2P，各自計分（不列入排行榜）
* **消耗大卡**：依手腳動作量估算（以 60 公斤計）
* **歌**：三首原創合成曲（含合成人聲 hey!／oh／yeah），也可以選手機裡自己的歌（自動抓 BPM 與第一拍；不列入排行榜）
* **AI 歌曲**：把 mp3 放進 `public/songs/`，在 `music.js` 的 `SONGS` 加一筆 `{ zh, file: 'songs/xxx.mp3', bars, bpm?, beat0? }`，bpm／beat0 沒填會自動偵測

## 程式

| 檔案 | 內容 |
|---|---|
| `public/core.js` | 姿勢與舞步、比對、編舞、判定、計分、自己的歌抓拍子（武俠篇共用同一份） |
| `public/app.js` | 流程、相機、全身定位（MediaPipe Pose Lite，放在自己網站上）、畫面、錄影、排行榜（武俠篇共用） |
| `public/theme.js` | 舞蹈篇的文字、顏色、配樂 |
| `public/music.js` | 三首歌的合成器編曲與音效 |
| `netlify/functions/scores.mjs` | 排行榜 API（Netlify Blobs）：今日／本週（台灣時間）／總榜，各留前 100 名，同一支手機只留最好的一次；武俠篇也用這個 |

測試：網址加 `?bot=0.9` 會用假人自動跳（不開相機），可以在電腦上看整個流程。

## 隱私

影像只在手機上分析，不會上傳。只有按「上傳成績」才送出暱稱、分數和一組隨機的裝置代碼。影片留在使用者手機裡。
