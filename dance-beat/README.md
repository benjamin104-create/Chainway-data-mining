# 全民律動王（舞蹈篇）

手機立起來、退後兩步，跟著動作卡跳舞；鏡頭即時判斷全身動作，跳完自動錄影、給分數，可以上傳排行榜。

網址：https://jaminepa-dance.netlify.app

## 玩法

* 三首原創歌（Web Audio 當場合成，沒有版權問題）：霓虹心跳 112 拍、夏日派對 118 拍、能量全開 126 拍，各約 1 分鐘
* 三種難度：簡單（只動手、一小節一個）、普通（加上蹲下、兩拍一個）、困難（全身、每四小節有一段一拍一個）
* 同一首歌、同一難度的動作數量與拍點固定（排行榜公平），出哪個動作每次隨機
* 判定：動作卡到判定圈前後一小段時間內，取最像的一格；PERFECT／GREAT／GOOD／MISS
* 分數滿分 10000＝準確度 9000＋最高連擊 1000；五顆星門檻 2000/4000/6000/8000/9300
* 結束畫面（分數卡）也錄進影片，存相簿或直接分享

## 程式

| 檔案 | 內容 |
|---|---|
| `public/core.js` | 14 個動作的定義（手腳每段骨頭的方向）、比對、譜面、判定、計分（武俠篇共用同一份） |
| `public/app.js` | 流程、相機、全身定位（MediaPipe Pose Lite，放在自己網站上）、畫面、錄影、排行榜（武俠篇共用） |
| `public/theme.js` | 舞蹈篇的文字、顏色、配樂 |
| `public/music.js` | 三首歌的合成器編曲與音效 |
| `netlify/functions/scores.mjs` | 排行榜 API（Netlify Blobs）：今日／本週（台灣時間）／總榜，各留前 100 名，同一支手機只留最好的一次；武俠篇也用這個 |

測試：網址加 `?bot=0.9` 會用假人自動跳（不開相機），可以在電腦上看整個流程。

## 隱私

影像只在手機上分析，不會上傳。只有按「上傳成績」才送出暱稱、分數和一組隨機的裝置代碼。影片留在使用者手機裡。
