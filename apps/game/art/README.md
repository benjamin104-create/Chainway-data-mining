# 美術素材放這裡

把圖檔丟進這個資料夾就好，其餘的（切圖、去背、轉成內嵌資料、接到遊戲裡）我來做。

## 怎麼上傳

在 GitHub 網頁上：

1. 進到這個資料夾（`apps/game/art/`），確認右上角的分支是
   `claude/tower-defense-game-design-fegjsg`
2. 按 **Add file → Upload files**
3. 把圖拖進去
4. 下面的 **Commit changes** 按下去

手機上也可以，用瀏覽器開 GitHub 網頁版（不是 App）。

## 檔名

不用特別改，原本的檔名就好。如果方便的話，用這種命名我這邊會少猜一輪：

## 幾件事先講在前面

- **白底沒關係**，我會把背景去掉。但如果你手上有**透明背景**的版本，那個最好——
  自動去背遇到物件本身就有白色的地方（例如白羽毛、銀邊）會咬掉一角。
- **一張圖裡放九宮格（3×3）沒問題**，我會自己切。只要每格的間距一致就好。
- **解析度不用壓縮**，原圖給我。內嵌進遊戲之前我會自己縮到合適的大小。
- 遊戲是以 Artifact 的形式發佈的，外部網址的圖片會被 CSP 擋掉，
  所以最後會把圖轉成內嵌的資料（data URI）。這件事我處理，你不用管。
